4. Optional execution changes

- YOLO final test: retain mode="evaluate"; set final_test_enabled=True and settings_frozen=True. The checkpoint and evaluation settings are checked before testing. Native Ultralytics metrics can differ from the ensemble's common evaluation protocol, so use test_comparison.csv for the cross-model comparison.
- YOLO fresh training: use mode="train" with both final-test controls False. The original 20-epoch, batch-16, patience-10 configuration is retained. This takes additional GPU time.
- RF-DETR fresh training: use mode="full-training", full_checkpoint=None, run_validation=True, final_test_enabled=False and settings_frozen=False. The original limit of 20 epochs, patience 4 and training time limits are retained. Finishing all 20 epochs is not guaranteed.
- Resume: the supplied .pt and .pth files are selected inference weights without optimizer state. They cannot resume the original training runs. RF-DETR's resume option requires a new run's full .ckpt, companion metadata and remaining time budget. Historical references to the original latest_resume.ckpt do not mean it is included.
- CPU preparation: set mode="preparation" and disable final testing. This runs checks and EDA without model inference. Local notebook preparation requires its imported packages: NumPy, pandas, Pillow, PyYAML, Matplotlib, tqdm and IPython; YOLO also uses Plotly/OpenCV, and RF-DETR's augmentation preview uses its training dependencies. Colab handles setup automatically.
